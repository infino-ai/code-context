Ask your own question. Both arms run at once, and each bar fills as its run happens, coloured by where the time is going.

What you're asking about

infino — the engine repository: a retrieval engine that stores data on object storage and runs SQL, full-text search and vector search over it. One file (a "superfile") is a valid Parquet file with BM25 and vector indexes spliced in; the supertable layer composes many superfiles into a queryable table with snapshot-isolated reads and an atomic-commit manifest.

Both arms see the same checkout. The grep arm reads it off disk; the infino arm queries the index of it. Questions that make an agent sweep many files are where the two diverge — a question one agent answers from a single file usually comes out level.
