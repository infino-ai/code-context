You will see larger performance improvement between frontier models and Infino Subagents on exploratory questions or on private data. On simple file lookups or open source code bases the frontier model already knows, the performance difference will typically be less.

    The engine repository: a retrieval engine that stores data on object storage and runs SQL, full-text search and vector search over it. One file (a "superfile") is a valid Parquet file with BM25 and vector indexes spliced in; the supertable layer composes many superfiles into a queryable table with snapshot-isolated reads and an atomic-commit manifest.

    how the three arms read it

    All three see the same files and get the same question. File Tools opens them one by one, the way a developer does today. The other two search the same files through two Infino indexes — an open-source one on your own machine and one in the cloud — and Subagents adds asking in plain English. Questions that send an agent across many files are where they come apart; one answered from a single named file usually comes out level.

    All three arms answer the same question at once, and each panel settles the moment its own arm finishes.
